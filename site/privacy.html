PhishNetra Privacy Policy

Effective 25 October 2026 · Applies to the PhishNetra browser extension and the PhishNetra web service.

Single purpose

PhishNetra detects phishing websites and protects users from them in real time. All data handling described here exists only to serve that purpose.

Data the extension sends

Only after you accept the in-extension disclosure, for each web page you open, the extension sends to the PhishNetra analysis server:

DataWhy
Page URLReputation, URL machine-learning and look-alike-domain checks
Page title and up to 5,000 characters of visible page textDetect pages that falsely claim to be a known brand
Structural counts (links, forms, password fields, iframes, scripts, images)Page-structure phishing model
Favicon URLVisual brand-impersonation check

The extension does not collect form input, passwords, cookies, browsing history, account information, location, or any identifier tied to you. No personal information is sold, shared with advertisers, or used for any purpose other than phishing detection.

Data stored on the server

The server stores a scan record (URL, domain, risk score, verdict, explanation, timestamp) to power the PhishNetra dashboard and improve detection. Records on the hosted demo are kept in temporary storage that is cleared automatically when the server restarts. Reports you submit ("report phishing" / "it's safe") update the shared block/allow lists.

Third parties

To judge a site the server may query public WHOIS registries for the domain's age and connect to the site to check its TLS certificate. No data about you is included in these lookups. The service is hosted on Vercel.

Your choices

You can pause protection, switch to monitor-only mode, or point the extension at your own self-hosted server from the toolbar popup, and uninstall at any time. The project is open source: github.com/Vedantt-dev/phishnetra.

Contact

Questions: open an issue on the GitHub repository above.

The use of information received from the extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
